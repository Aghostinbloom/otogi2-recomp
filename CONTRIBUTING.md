# Contributing

Thank you for your interest in otogi2-recomp.

## Pull requests

Pull requests are not accepted at the moment. Pull requests opened anyway will be closed without review.

## Issues

Issues are welcome for:

- Crashes, graphics or audio differences from the Xbox, once there is a build to run. Attach the log file the game writes.
- Findings about the game's executable: function addresses, structures, behaviour.

## Never post game content

Do not attach or link disc images, `default.xbe`, extracted game files, lifted C or disassembly listings, in issues or anywhere else in this repository. Addresses, names and short descriptions of behaviour are fine.
